    녹화된 시연

      아직 녹화가 없습니다. 실시간 실행을 하면 자동으로 녹화됩니다.

      무엇을 보여주나요?

      1. 같은 질문을 Claude Code 두 개에 동시에 보냅니다.
      2. 왼쪽은 Davi가 먼저 난이도를 보고 가벼운 모델(haiku), 중간 모델(sonnet), 고성능 모델(opus) 중 하나를 고릅니다.
      3. 오른쪽은 늘 고성능 모델(opus)만 씁니다.
      4. 두 쪽 모두 메인 에이전트는 같은 모델이고, 서브에이전트 모델만 다릅니다.
      5. 정답과 비용을 나란히 비교합니다.

      왼쪽에서 질문을 고르고 실행해 보세요.

      1. 질문 전달
      2. Davi가 난이도 판단
      3. 모델 배정
      4. 풀이
      5. 결과 비교

      Davi가 본 난이도

      판단 중…

      쉬움어려움

      시간은 어디에 쓰였나?

      메인 에이전트 준비 Davi 판정 전달 (플러그인·Claude Code) 서브에이전트 풀이 메인 에이전트 마무리

      시각은 플러그인 로그 기준입니다. 같은 모델이라도 답을 길게 쓰면 풀이 시간이 길어집니다.

      다른 판정자였다면?

      원래 질문을 세 판정자에게 똑같이 물었을 때 고른 모델입니다. 실제 배정은 메인 에이전트가 서브에이전트에게 넘긴 지시문을 보고 판단하므로 조금 다를 수 있습니다.
