      시간은 어디에 쓰였나?

      메인 에이전트 준비 Davi 판정 전달 (플러그인·Claude Code) 서브에이전트 풀이 메인 에이전트 마무리

      시각은 플러그인 로그 기준입니다. 같은 모델이라도 답을 길게 쓰면 풀이 시간이 길어집니다.

      다른 판정자였다면?

      원래 질문을 세 판정자에게 똑같이 물었을 때 고른 모델입니다. 실제 배정은 메인 에이전트가 서브에이전트에게 넘긴 지시문을 보고 판단하므로 조금 다를 수 있습니다.
